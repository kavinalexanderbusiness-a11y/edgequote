# Bundled application fonts

DM Sans and Syne are stored here so application builds do not depend on
Google Fonts network access. RootLayout uses next/font/local with the same
CSS variable names as before.

Retrieved 2026-09-10 from the Google Fonts repository:

- https://github.com/google/fonts/tree/main/ofl/dmsans
- https://github.com/google/fonts/tree/main/ofl/syne

The original SIL Open Font License files are included alongside the fonts.
DM Sans supports weights 100–1000; Syne supports 400–800.

Next.js local-font documentation:
https://nextjs.org/docs/app/getting-started/fonts#local-fonts
